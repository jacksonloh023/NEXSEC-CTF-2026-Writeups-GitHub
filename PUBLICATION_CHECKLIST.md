# Publication Checklist

Before uploading this repository publicly:

- [ ] Add the team name where required.
- [ ] Add the solver name(s) where required.
- [ ] Confirm the NEXSEC CTF rules permit publication at this time.
- [ ] Confirm public disclosure of recovered flags is allowed.
- [ ] Review screenshots for unintended personal or infrastructure information.
- [ ] Check every command and output against the team's original evidence.
- [ ] Remove this checklist if it is not needed in the public repository.
